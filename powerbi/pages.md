# Power BI ページ設計 ― 経営KPI・予実管理ダッシュボード（4ページ）

前提： `model.md` のモデル、`measures.dax` のメジャー。Excel版（D1〜D4）と見せ方を揃える。
共通： 全ページ右上に年度スライサー（DimDate[fiscal_year]、既定＝最新年度）と部門スライサー（DimDepartment[department]、既定＝全社）を置く。金額は千円単位で表示し、カードには単位「千円」を明記する。各ページのフッターに「デモ（合成）データ／実在企業の実績ではありません」の注記を置く（実務案件では実データに差し替えた時点で外す）。

## ページ1：KPI概要（Excel D1相当）

- カード×6： [売上高 実績]（累計）／[売上高 YTD達成率]／[売上高 累計前年比]／[営業利益 実績]（累計）／[営業利益率 実績]／[売上高 着地予想]
- 折れ線＋柱： 月次 [売上高 実績]（柱）と [売上高 予算]（線）、軸＝DimDate[month]
- 柱： 年度別 [売上高 実績]（FY2023〜。進行中年度は [売上高 着地予想] を別系列で重ねる）
- 表： 年度推移（年度／売上 予算・実績・達成率／営業利益 予算・実績）― FactFiscalYearSummary をそのまま使う静的表と併記可

## ページ2：予実対比（Excel D2相当）

- 表： 月次マトリクス（行＝月、列＝売上 予算・実績・差異・達成率・累計達成率、営業利益 予算・実績・差異）。差異は条件付き書式（マイナス＝赤）で色分け
- 柱： 月次 [売上高 差異]（プラス／マイナスで色分け）
- 折れ線： [売上高 累計達成率] の推移。100%の定数線を重ねる
- 読み方メモ（テキストボックス）： 異常値の月の要因を書く欄。サンプルでは「9月：卸売部門の出荷遅延」を記載

## ページ3：部門別（Excel D3相当）

- 表： 部門別（行＝部門＋全社、列＝売上 予算・実績・達成率・前年比・構成比、営業利益 実績・利益率）
- 棒： 部門別 [売上高 達成率]（100%線つき、ソート＝達成率の昇順で課題部門を上に）
- 折れ線： 部門別 月次 [売上高 実績]（凡例＝部門）
- ドリル： 部門をクリックするとページ2がその部門にフィルタされるよう、ドリルスルー（ページ2）を設定する

## ページ4：着地予想（Excel D4相当）

- カード×3： [売上高 着地予想]／[売上高 着地予想（調整）]／[売上高 着地達成率見込]
- 積み上げ柱＋線： 対象別（全社・部門）に [売上高 実績累計（年度内）]＋[売上高 残期間予算] を積み上げ、[売上高 通年予算] を線マーカーで重ねる
- 表： 着地内訳（対象／実績累計／残期間予算／着地（予算ベース）／着地（調整）／通年予算／達成率見込2種／営業利益 着地）― FactLandingFY2026 と表示を一致させる
- 前提テキストボックス： 2シナリオの前提と限界（残期間が予算どおり進む前提／直近3か月達成率が続く前提、季節性は残期間予算側に内包）を明記する

## 実務案件での差し替えポイント

- FactMonthlyPL を会計ソフトの月次PL＋予算マスタに差し替える（列構成は model.md のとおり）
- 実績の入っていない月は actual を空欄のまま取り込む（着地メジャーの残期間判定が actual の有無に依存するため）
- 部門名・勘定名は DimDepartment／DimAccount の一意化で自動追随する。勘定を増やす場合は measures.dax の基本集計ブロックに同型のメジャーを追加する
