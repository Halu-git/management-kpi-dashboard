# BUILD NOTES ― 経営KPI・予実管理ダッシュボード（Power BI）

## 2026-11-19 実機検証で見つかったDAXの欠陥と修正

### 欠陥
累計・着地系のメジャーが、選択中の会計年度ではなく**全年度合計**を計算していた。
年度スライサーで FY2026 を選んでも、実績累計・着地予想が他年度を含む値になり、
最終実績月インデックスも 7（FY2026の10月）ではなく 12 を返していた。

### 原因
対象メジャーが `FILTER ( ALL ( DimDate ), DimDate[fiscal_month_index] <= ... )` の形で
月インデックスだけを条件にしていた。`ALL ( DimDate )` は DimDate への全フィルター
（年度スライサーの選択を含む）を解除するため、月インデックス条件が全年度の月に
適用され、年度をまたいだ集計になっていた。
`売上高 通年予算` も `CALCULATE ( [売上高 予算], ALL ( DimDate ) )` で年度条件が消えていた。
`最終実績月インデックス` は `ALL ( FactMonthlyPL )` 経由で全年度の実績月を見ていた。

### 修正内容
各メジャーに「選択中の会計年度」を固定する条件を追加した。
`VAR CurFY = MAX ( DimDate[fiscal_year] )` で選択年度を取り、
`FILTER` の条件に `DimDate[fiscal_year] = CurFY && ...` を加える形に統一。
`最終実績月インデックス` は CALCULATE のフィルター引数に `DimDate[fiscal_year] = CurFY` を追加。

修正した9メジャー：
- 売上高 累計実績
- 売上高 累計予算
- 最終実績月インデックス
- 売上高 実績累計（年度内）
- 売上高 残期間予算
- 売上高 通年予算
- 売上高 直近3か月達成率
- 営業利益 実績累計（年度内）
- 営業利益 残期間予算

基本集計・利益（派生）・予実差異／達成率・前年比系・売上高 構成比は変更なし
（前年比系は元々 `fiscal_year = CurFY - 1` 等で年度を明示していたため影響なし）。

### 検証（Power BI Desktop 実機、FY2026選択時）
- 売上高 実績累計（年度内）＝ **707,458**（千円）
- 売上高 着地予想 ＝ **1,278,115**（千円）
- 最終実績月インデックス ＝ **7**

修正前は実績累計・着地予想とも約4M（全年度合計）、最終実績月インデックスは12だった。

### 教訓
`ALL ( テーブル )` を使うメジャーは、そのテーブルにかかるスライサー条件
（年度など）も一緒に消える。期間系のメジャーを書くときは、残したい
ディメンション条件（年度）を VAR で固定して FILTER 条件に明示すること。

## 2026-11-19 第2弾修正 ― ページ1（KPIカード）構築時の検算で判明

### 問題
ページ1のKPIカードは月を選択しないため、累計系メジャーの CurIdx
（MAX の fiscal_month_index）が 12 になり、累計が年度末まで伸びてしまった。
実機表示では [売上高 累計達成率] が 53.02%（通年予算比）、
[売上高 累計前年比] が -41.65%（前年フル期間比）となり、
いずれも「実績のある最終月まで」のYTD値ではなかった。

### 修正内容
実績のある最終月（[最終実績月インデックス]）でキャップしたYTD系を用意し、
カード表示はそちらに切り替える。
- 新規： [売上高 累計予算（実績月まで）] ― 予算累計を最終実績月でキャップ
- 新規： [売上高 YTD達成率] ＝ [売上高 実績累計（年度内）] ÷ [売上高 累計予算（実績月まで）]
- 上書き： [売上高 累計前年比] ― 当年側を [売上高 実績累計（年度内）] に、
  前年側のキャップも CurIdx から LastIdx に変更
- pages.md のページ1カード定義を [売上高 累計達成率] → [売上高 YTD達成率] に変更
  （ページ2の表・折れ線の [売上高 累計達成率] は月次推移用として据え置き）

### 検証値（CSV突合、FY2026）
- YTD達成率 ＝ **92.64%**（累計予算 763,647 千円）
- YTD前年比 ＝ **+1.68%**（前年同期間 695,746 千円）
